# Machine Learning Assignments

This repository contains the assignments for the **Machine Learning** course at CSD AUTH during the 2024–2025 academic year.

## Contents

### Assignment 1: Linear Models
- **Logistic regression** modeling 
- Multi-class classification: **One-vs-One** and **One-vs-Rest**
- **Datasets:** Digits, Breast Cancer

### Assignment 2: Decision Trees and Model Evaluation
- Decision tree regression using different splitting criteria
- Hyperparameter tuning and model selection
- Cross-validation methods: **Leave-One-Out**, **K-Fold**, **Nested CV** 
- **Dataset:** Diabetes

### Assignment 3: Ensemble Methods
- Deterministic **Random Subspace Method** implementation
- **AdaBoost** with weighted sampling
- Ensemble learning and performance comparison
- **Dataset:** Pima Indians Diabetes (OpenML)

## Dependencies

The notebooks require the following Python libraries:

- `numpy` — numerical computations and array operations  
- `pandas` — data manipulation and analysis  
- `scikit-learn` — ML algorithms, datasets, model selection, preprocessing, and evaluation  
- `matplotlib` — plotting and data visualization
